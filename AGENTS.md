# Repository agent guidance

## Organization source contributions

Ship useful work for Arta today, and leave each improvement easy to understand, extract and reseat into the independently built Foundry later. Follow the [organization contribution guide](https://github.com/wildeboer-ai/guide/blob/5b41f7aec904ad42cbeb1435384f92555eb3555c/CONTRIBUTING.md#build-useful-capabilities-for-later-intake). Preserve existing callers and this repository’s contracts; describe affected interfaces, dependencies, effects, tests and limits in the existing PR or receipt. Keep the separation proportionate to the actual change. This guidance grants no private Foundry access, live-effect, push or merge authority.

Repository-specific rules remain in [CLAUDE.md](CLAUDE.md); read its existing guidance and applicable contracts before changing source.
